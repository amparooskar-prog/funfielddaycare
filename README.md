# Fun Field Day Care and Playschool

Responsive one-page website concept prepared by Habi Digital Group. Saved for review; no deployment or GitHub Pages workflow is configured.

## Preview

Open `index.html`, or run `python -m http.server 4173 --bind 127.0.0.1` in this directory and visit http://127.0.0.1:4173.

No build step, package installation, or backend required. Contact buttons open the school's phone, email, Messenger, Facebook and directions. FAQs and the mobile menu work locally. The Facebook Page Plugin and Google Fonts require internet access; the Facebook panel includes a permanent fallback link. Facebook may restrict its embedded feed according to browser/privacy/login settings.
